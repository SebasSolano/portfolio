## 🔍 Overview
GradeGain is an educational platform designed to help students improve their academic performance through a reward-based task system. The platform allows teachers to create tasks, assign them to students, and reward them with notes and medals based on their performance.

## ✨ Features
- 👤 User Authentication : Secure login and registration system
- 📚 Task Management : Create, assign, and track tasks
- 🏅 Reward System : Award medals and notes to students
- 📊 Progress Tracking : Monitor student performance
- 🎯 Subscription Plans : Different tiers for different needs
- 👥 Referral System : Invite friends and earn rewards
- 🎫 Support Tickets : Get help when you need it
- 📱 Responsive Design : Works on desktop and mobile devices
- 📜 Certificate Generation : Create and download achievement certificates

## 🛠️ Tech Stack
- Frontend : Vue.js 3 with Composition API
- UI Framework : Tailwind CSS, Ant Design Vue
- Authentication : Firebase Authentication
- Database : Firebase Firestore
- Storage : Firebase Storage
- PDF Generation : jsPDF
- Build Tool : Vite
- Deployment : Vercel

## 🚀 Getting Started
### Prerequisites
- Node.js (v14 or higher)
- npm or bun package manager
### Installation
1. Clone the repository:
```bash
git clone https://github.com/yourusername/gradegain-client.git
cd gradegain-client
 ```

2. Install dependencies:
```bash
npm install
# or
bun install
 ```

3. Set up environment variables:
   Create a .env file in the root directory with your Firebase configuration.
4. Start the development server:
```bash
npm run dev
# or
bun run dev
 ```

## 💻 Usage
### User Dashboard
The main dashboard provides an overview of your tasks, rewards, and progress. Navigate through the sidebar menu to access different features.

### Support System
Need help? Use the support ticket system to get assistance from our team:

1. Go to the Support section
2. Create a new ticket
3. Describe your issue
4. Wait for a response from our support team
### Certificate Generation
After completing tasks, you can generate certificates to showcase your achievements:

1. Navigate to the certificates section
2. Select the task or achievement
3. Click "Generate Certificate"
4. Download the PDF certificate
